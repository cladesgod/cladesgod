## About

I design and build AI systems that move beyond demos: LLM agents, RAG pipelines, evaluation workflows, and production-grade automation services.

My current research focuses on the **autonomy of Large Language Model agents**, especially in automated personalized feedback, SQL education, and agentic assessment systems. Professionally, I work across applied AI architecture, multi-agent orchestration, machine learning pipelines, and LLM-driven product development.

I am currently a **Lead AI Systems Architect at Psynalytics**, a **Ph.D. researcher at Istanbul Technical University**, and an **R&D Researcher on a Turkcell & ITU TÜBİTAK 1505 project**.

## Selected Projects

### [APA 7 Citation Helper](http://tchain.ai)
Specialized GPT agent for automated academic citation formatting.

- 100K+ users
- 4.3/5.0 satisfaction rating on the GPT Store
- Focus: academic writing automation, structured citation generation, user-facing AI utility

### Automated ECTS Transfer System
Agentic framework for matching cross-university curricula using semantic similarity and LLM-assisted reasoning.

- Built with LangChain and LangGraph
- Designed for curriculum alignment and transfer-credit decision support
- Joint research work with Başar Öztayşi

### AI-Powered Exam Grading Pipeline
Automated assessment workflow for consistent grading and feedback generation.

- Uses LangGraph for orchestration and LangSmith-style evaluation workflows
- Focused on SQL education, deterministic grading, and personalized feedback
- Related to ongoing Ph.D. research on LLM agents in educational systems

### Enterprise LLM Data Correction Pipeline
LLM-driven preprocessing and correction pipeline for Turkcell pre-legal workflows.

- Automates complex administrative data correction tasks
- Deployed as a scalable service-oriented workflow
- Combined ML pipelines with LLM-based correction and validation

### Healthcare AI Translation and Prediction Systems
Production AI systems developed during AI R&D leadership work at MLPCare.

- RAG-based medical translation pipeline with human-in-the-loop feedback
- Docker + FastAPI deployment
- Reduced translation turnaround from days to seconds
- Ensemble learning for disease prediction and LSTM-based forecasting for hospital operations
